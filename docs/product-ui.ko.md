# 오버레이 UI 구성 기준

게임 중 짧게 확인하는 도구이므로 이름과 가격을 가장 먼저 읽고, 가격의 의미를 그다음 확인하게 구성한다. 기능의 구현 상태를 과장하는 배지나 연결 상태로 오해할 수 있는 표시는 넣지 않는다.

## 화면 순서

1. 제품명과 현재 작업: 아이템 시세.
2. 동일한 색과 크기의 F6 전체 화면 / F7 마우스 주변 버튼.
3. 인식 수, 가격 확인 수, 최고 참고가. 보상 선택지를 합산한 총액은 보여주지 않는다.
4. 가격순 목록과 가격 유무 필터. 제거한 이름 검색·리그 입력·자동 스캔 UI를 다시 추가하지 않는다.
5. 판매 전 옵션 비교. 사용하지 않을 때는 접어서 목록 공간을 확보한다.
6. 도움말과 성능 정보. 자세한 실행 지표는 주 화면에서 숨긴다.
7. 짧은 작업 상태와 작은 상태 점.

## 색과 글자

| 역할 | 색 | 목적 |
| --- | --- | --- |
| 앱 배경 | `#151719` | 게임의 색과 경쟁하지 않는 차콜 |
| 카드 | `#1d2024` | 읽기 영역 구분 |
| 본문 | `#f3f5f7` | 아이템 이름과 주요 정보 |
| 보조 설명 | `#bac3ce` | 충분한 대비를 유지하는 회색 |
| 엑잘 | `#f2ce88` | 금색의 화폐 값 |
| 신성 | `#91bfff` | 엑잘과 구분하는 파란색 |
| 조회 중 | `#6bd5a1` | 작은 상태 점에만 사용 |
| 오류 | `#ff9191` | 실제 오류에만 사용 |

이름 17px, 가격 18px, 베이스 13px, 가격 기준 12px. 신성·엑잘의 크기와 굵기는 같다. 좁은 창에서는 이름 16px, 두 가격은 17px로 함께 조정한다. Pretendard 가변 폰트는 로컬 파일을 사용한다.

카드 배경 기준 계산한 대비는 본문 14.96:1, 보조 설명 9.18:1, 금색 10.87:1, 파란색 8.64:1이다. 이는 CSS 색상 자체의 계산값이며, 창 불투명도 94%로 합성된 실제 게임 화면의 대비 측정값은 아니다.

## 가격 카드와 상태

이름과 베이스는 왼쪽에서 읽고, 두 화폐는 오른쪽에 정렬한다. 가격 기준과 매물 보기 버튼은 같은 아랫줄에 둬 카드가 불필요하게 길어지지 않게 한다. 베이스 참고가·고유 최저·동일 등급 최저를 구분하고, 실제 옵션 평가 가격으로 오해하지 않게 한다.

조회 중인 가격은 `조회 중…`, 필요한 정보가 없으면 `확인 필요`로 표시한다. 0으로 대체하지 않는다. 첫 실행, 인식 결과 없음, 필터 결과 없음에는 다음 행동을 안내한다. 대기는 회색, 조회 중은 초록색, 실패는 빨간색이다. 점 자체가 시세 서버 연결 상태를 뜻하지는 않는다.

판매 비교에서는 가격 범위와 비교 수를 먼저 표시한다. 적용한 옵션은 펼쳐서 확인하고, 제외된 옵션은 경고와 목록으로 확인한다. 가격 범위는 조회한 매물 기준이며 전체 시장 범위를 보장하지 않는다.

## 자원과 검증

추가 UI 라이브러리, 애니메이션, 배경 흐림, 폰트 CDN, 반복 UI 타이머를 쓰지 않는다. 기존 행 재사용과 변경된 값만 갱신하는 방식을 유지한다. 테스트는 필터, 초점 유지, 두 화폐, 옵션 제외 경고와 거래 링크를 검증한다.

이번 브라우저 미리보기는 실행 환경 오류로 열리지 않았다. 실제 Electron 창의 잘림·스크롤·게임 배경 위 가독성은 별도 검증이 필요하다.
