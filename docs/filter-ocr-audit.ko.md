# 활성 필터 OCR 시험 — 2026-10-05

사용자 PC의 활성 필터는 OnlineFilters/ER174xSj (NeverSink-2semistr-PoE2)였다.
서미누기 공개 색상 사전도 분석했다: https://seominugi.com/api/poe2/filter-colors
검정 글자/밝은 배경, 보라 및 베이지 글자가 있으므로 고정 밝은 글자 팔레트만으로는 부족하다.
색상은 희귀도나 가격 확정 근거로 사용하지 않는다.

## 구현

- 게임 설정에서 활성 필터를 읽고 온라인 캐시 또는 로컬 .filter의 SetTextColor를 추출한다.
- 5초간 파일 확인을 캐시하고 파일 mtime/크기 변경 시 다시 파싱한다. 상시 폴링은 없다.
- 색상 조회 테이블과 균일한 주변 배경 대비를 이용하는 시험용 전처리를 추가했다.
- 기본 경로에서 사용하지 않는 라벨 영역 추출 비용을 제거했다.
- Import 파일의 재귀 해석, 배경/글자 크기별 영역 추출은 아직 구현하지 않았다.

## 검증과 적용 제한

첨부 이미지 13장의 기존 인식 개수를 유지했다. 전체 화면 두 장도 각 7개를 유지했다.
그러나 같은 새 게임 캡처에서 기존 전처리는 16행, 새 전처리는 13행을 반환했다.
기존 결과에는 중복 행도 있어 개수는 정답률이 아니지만, 대장장이의 숫돌 등 기존 인식 누락이 발생했다.
따라서 기본 OCR로 승격하지 않았다. 시험할 때만 POE_OCR_FILTER_PROFILE=1로 실행한다.
프로파일을 사용해도 모든 필터를 지원하거나 인식률 향상을 보장하지 않는다.

검증 결과: %TEMP%/poe2-filter-profile-final/results.json
같은 프레임 기존 전처리: %TEMP%/poe2-filter-same-baseline/results.json 의 첫 항목
단위 테스트 74개 통과, 문법 검사 통과. 전처리 시험은 실제 캡처를 OCR에 전달한 것으로 앱 버튼 클릭 검증은 아니다.
