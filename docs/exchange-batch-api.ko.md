# 오버레이 일괄 시세 연결 상태

2026-10-05 오버레이 F6/F7 스캔을 `POST /api/overlay/prices`로 연결했습니다.
인식한 항목을 중복 제거해 한 번 보내며, 수량은 응답 후 각각 곱합니다.
`commodity`는 서버의 `currency`로, 서판은 `tablet`으로 변환합니다.
같은 요청은 60초 캐시와 진행 중 요청 공유를 사용하며 캐시는 최대 16개입니다.
스캔은 전체 `/api/markets`나 외부 거래 API를 추가 호출하지 않습니다.
옵션 복사 상세 검색은 기존 경로를 유지합니다.

희귀 전체 이름과 같은 베이스의 고유 후보를 한 요청에 포함합니다.
정확한 이름이 없을 때 고유 후보 참고 범위를 표시하며 희귀 아이템 가격으로 확정하지 않습니다.
경로석 등급·젬 레벨 시세 등 서버에 없는 값은 확인 필요로 남깁니다.
30분 이상 오래된 환율·시세는 표시하지 않습니다. 서버 실패는 명시적으로 알립니다.

운영 서버에서 일괄 API HTTP 200과 응답 구조를 확인했습니다.
마지막 실제 검사에서는 환율이 약 41분 오래되어 서버가 stale을 반환했습니다.
수집기 갱신 상태를 확인해야 하며 오버레이는 이 가격을 표시하지 않았습니다.

웹 `backend/overlay_prices.py` 응답에 항목 id를 추가했습니다.
이 변경은 웹 서버에 배포한 뒤 재시작해야 고유 아이템 링크도 정확한 웹 항목으로 연결됩니다.
화폐는 기존 id로 연결 가능합니다.

응답에는 ETag, Server-Timing과 snapshotVersion이 이미 있습니다.
수집기는 요청과 분리되어 있습니다. 향후 네트워크 지연과 수집 실패 원인을 별도로 측정해야 합니다.
