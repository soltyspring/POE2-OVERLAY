# 제작 투자 판단 기능 설계

## 목표

Ctrl+C로 복사한 장비를 기준으로, 현재 보유 옵션이 목표 옵션과 얼마나 맞는지, 다음 오브를 쓸 때 목표 상태에 도달할 확률과 기대 손익이 어떤지 보여준다. 가격은 참고 시세로 표시하고, 실제 판매가나 게임 결과를 보장하지 않는다.

## 데이터 경계

- 계정 토큰을 설치된 다른 앱에서 읽거나 저장하지 않는다. 프록시 우회와 문서화되지 않은 GGG 내부 API 호출도 하지 않는다.
- GGG 개발자 문서가 지원한다고 명시한 API·데이터만 새 기능의 공식 데이터 연동으로 사용한다. 현재 문서의 계정 보관함 리소스는 PoE1 전용이고, 문서는 문서화되지 않은 내부 API 역공학을 금지한다고 밝힌다.
- 공식 Currency Exchange API(`/api/currency-exchange/poe2`)는 시간 단위의 과거 화폐 교환 집계다. 현재 시간 데이터나 장비 옵션별 시세를 주지 않으므로, 제작 오브 비용의 장기 추세/대조용이지 실시간 장비 감정 API가 아니다.
- 우리 가격 서버의 기존 공개 응답을 재사용한다. 화폐 가격과 장비 비교가는 입력 날짜·리그·출처를 함께 표시한다.
- 제작 옵션 풀은 리그 패치와 연결된 버전 데이터로 분리한다. 출처, 라이선스, 패치, 데이터 생성 시점, 추정 여부를 매니페스트에 기록한다. 무게 데이터가 검증되지 않으면 확률·기대값을 표시하지 않는다.

## 구성

1. **아이템 수집** — 게임 클립보드 텍스트를 로컬에서 파싱해 희귀도, 베이스, 아이템 레벨, 암시·명시 옵션, 숫자 범위, 복사문에 포함된 접두어/접미어 단서를 구조화한다. 원문과 계정 식별정보는 저장하거나 서버에 보내지 않는다.
2. **목표 프로필** — 사용자가 목표 유효 옵션을 체크하고 중요도를 정한다. 생명력/저항, 에너지 보호막, 무기 피해/속도 같은 기본 프리셋은 편의 기능이고, 빌드별 목표 편집이 우선이다.
3. **규칙 엔진** — 베이스·아이템 레벨·현재 옵션·충돌 그룹·희귀도별 제한을 바탕으로 각 오브의 유효 결과 공간을 만든다. 오브 적용은 순수 함수로 모델링해 입력 아이템을 바꾸지 않고 결과 분포를 계산한다.
4. **시장 가격** — 현재 아이템의 비교가와 목표 결과 아이템의 비교 범위를 분리한다. 여러 옵션을 한 번에 조회·캐시하고, 호가를 실거래가로 표현하지 않는다.
5. **투자 판단** — 각 액션의 성공 확률, 목표 옵션 획득 확률, 기대 비용, 결과 가격 범위를 계산한다. 다음 오브의 가치는 `결과별 확률 가중 가격 + 실패 결과의 잔존가치 - 앞으로 쓸 오브의 기대 비용`으로 계산한다. 이를 지금 팔 수 있는 기준가와 비교해 계속 제작/판매/보류를 제안한다. 이미 지불한 비용은 매몰 비용으로 다시 빼지 않는다. 시뮬레이션 표본 오차와 데이터 신뢰도를 같이 보여준다.

## 단계별 출시

- **1단계: 입력 검사(현재 시작)** — 복사 아이템에서 희귀도·베이스·아이템 레벨·사전에서 읽은 옵션 줄을 구조화하고, 현재 거래 비교 결과 옆에 제작 분석 입력을 표시한다. 보관함은 화폐 항목을 슬롯별로 수동 등록해 투명 오버레이에 고정하는 경로를 시작했다. 데이터가 없을 때는 성공률을 만들지 않는 동작까지 구현한다.
- **2단계: 목표 프로필** — 옵션 사전을 바탕으로 목표 옵션을 선택하고 저장한다. 아직 확인되지 않은 텍스트는 목표 옵션으로 확정하지 않는다.
- **3단계: 패치 데이터 어댑터** — 허용되는 출처와 라이선스를 확인한 버전 데이터만 로드하고, 베이스/모드/무게/충돌 그룹/오브 규칙의 정합성을 검증한다. 출처가 거래소 표본 추정이면 UI에서도 추정치로 표시한다.
- **4단계: 결정론적 확률 엔진** — 기본 오브부터 구현하고 알려진 확률 예시와 수동 계산으로 검증한다. 데이터가 불완전하거나 현재 패치와 맞지 않으면 해당 액션을 비활성화한다.
- **5단계: 비용·가치 비교** — 오브 시세와 목표 결과 비교 매물을 연결해 기대 비용, 손익 범위, 성공률을 한 화면에 보여준다.

## 해석 원칙

- 복사문에서 접두어/접미어 표시가 없으면 옵션 줄 수를 슬롯 수로 취급하지 않는다. 한 개 옵션이 여러 줄을 차지하거나 사전에서 매칭되지 않을 수 있다.
- 옵션 중요도는 캐릭터 빌드와 목표에 따라 달라지므로 보편적인 “유효 옵션”을 단정하지 않는다.
- 거래소 매물로 추정한 모드 가중치는 실제 게임 확률과 다를 수 있다. 가중치 근거가 확인될 때까지 평균 손익/정확 확률을 노출하지 않는다.
- 거래 비교가는 공개 호가의 표본이다. 실제 체결 가격과 구분하고 조회 표본 수·시간·통화를 보여준다.
