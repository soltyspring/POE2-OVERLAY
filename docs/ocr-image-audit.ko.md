## 수정 및 결정

- 빈 사전 이름 제거: 비아이템 OCR 줄에서 빈 카드가 생성되는 문제를 막았다.
- 영어 병기의 숫자 오독 허용: 한국어 사전에 정확히 일치할 때만 G01den 부분을 제거한다.
- 경로석 중복 사전: 화폐·장비 목록에 동시에 있어도 등급 검색 항목을 우선한다.
- 플라스크 베이스 사전 추가: 화면 글자 인식 문제와 사전 누락 문제를 분리했다.
- 노란 라벨 재시도에서 긴 세로 테두리를 제거한다. 폭풍 눈 문제는 해결됐다고 처리하지 않는다.
- 자동 영역 압축은 기본 비활성화했다. 한 화면에서는 빠르지만 다른 화면에서 인식 수가 줄어드는 회귀를 실제 확인했다. `POE_OCR_PACKED=1`로만 실험한다.

현재 남은 주요 과제는 밝은 색 배경·검은 글씨 라벨과 강조된 폭풍 눈 이름이다. 모든 사진이 완벽하게 인식됐다는 결론은 아니다.

## 재현

`scripts/benchmark-images.cjs`를 Electron으로 실행한다. 첫 번째 인수는 `{file: 절대경로}` 배열의 JSON 파일, 두 번째는 결과 저장 폴더다. 모니터도 새로 캡처한다. 테스트는 창을 클릭하거나 게임 입력을 보내지 않는다. 저장된 결과를 읽어 누락·오인식을 실제 사진과 대조해야 한다.
