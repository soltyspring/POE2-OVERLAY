# POE2-OVERLAY

한국어 PoE2 바닥 아이템을 화면에서 읽고 엑잘 기준으로 정렬하는 **Windows 초기 프로토타입**입니다.

## 우분투 POE2-Exchange 시세 연결

현재 기본 서버는 `https://poe-exchange.tail37463f.ts.net`입니다. 별도 환경변수 없이 실행해도 이 서버를 사용합니다. 리그 입력 UI 없이 `Forbidden Rites`를 사용합니다. 다른 리그는 실행 전 `POE_LEAGUE` 환경변수로 지정합니다. 주소를 바꾸려면 아래 환경변수를 사용합니다.

[POE2-Exchange](https://github.com/soltyspring/POE2-Exchange)의 기존 `GET /api/markets?league=...`를 사용합니다. DB 파일을 복사하거나 SQLite를 원격으로 직접 열지 않고, 서버가 반환한 리그별 현재 가격을 읽습니다. 서버 수정이나 DB 스키마 변경은 필요하지 않습니다.

오버레이를 종료한 후, 접속 가능한 서버 주소를 설정하고 실행하세요.

```powershell
$env:POE_EXCHANGE_URL = 'http://127.0.0.1:18000'
npm start
```

위 주소는 기존 SSH 터널이 `18000 → 우분투 127.0.0.1:18080`으로 열려 있을 때의 예시입니다. Tailscale HTTPS 주소를 쓰면 해당 주소로 바꾸세요. 우분투 README 기준 서버는 loopback에 바인딩되어 있어 LAN IP에 포트만 붙여서는 연결되지 않을 수 있습니다. 서버에서 수집 중인 리그와 `POE_LEAGUE`가 같아야 합니다.

- 서버 전체 스냅샷 1회로 분류별 poe.ninja 가격 요청을 대체하고 60초 동안 재사용합니다. 처음에는 한국어 공식 아이템 사전도 받습니다.
- 같은 리그의 엑잘 행을 기준으로 환산합니다. 서버의 집계 시세이며 고유/옵션별 거래 최저가로 표시하지 않습니다.
- 30분 이상 오래된 가격은 제외합니다. 서버 접근이 4초 안에 실패하거나 환율이 없으면 기존 직접 조회로 전환하고 경고를 표시합니다.
- 화면에 `POE2-Exchange DB` 또는 `poe.ninja 직접 조회` 출처와 데이터 기준 시간을 표시합니다.
- 현재 연결은 화폐·소모품 시세를 가속합니다. 고유·젬·희귀 옵션의 공식 매물 검색은 그대로 별도 호출합니다.
- SQLite가 있어도 해당 리그가 서버에 없으면 기존 `/api/markets`가 최초 수집을 시도하므로 응답이 느릴 수 있습니다.

연결/응답 시간을 확인하려면 `node scripts/exchange-smoke.cjs <서버 주소> "리그 이름"`을 실행하세요. 실제 우분투 주소 연결은 주소 확인 후 검증해야 하며, 로컬 HTTP 계약·환산·캐시·장애 복구를 포함한 테스트 20개가 통과했습니다. 실서버 지연 개선 수치는 아직 측정하지 않았습니다.

## 기본 실행

스캔 조작은 **F6 전체 화면**, **F7 마우스 주변** 두 가지만 제공합니다. 자동 스캔·영역 선택·리그 입력 UI는 제거했습니다. F7은 마우스 중심 900×900 DIP 영역을 화면 경계 안으로 조정해 OCR합니다. 전체 모니터 캡처 후 해당 영역을 잘라 읽으므로 화면 캡처 자체는 계속 전체 모니터입니다.

같은 화면이면 PNG 생성·저장·OCR을 생략하고, 사전·가격 캐시와 변경된 행만 갱신하는 최적화를 유지합니다. OCR 워커는 60초간 사용하지 않으면 종료합니다. 처리 시간은 **스캔 성능·도움말**에서 확인합니다.

메모리 캐시는 최대 128개로 제한하고 만료된 매물 결과를 제거합니다. 공식 사전은 사용하는 필드만 보관하며, 서버 원본 스냅샷 대신 환산된 가격 데이터를 보관합니다. 캡처 이미지는 저장 단계 이후 참조를 남기지 않아 가격 검색 중에도 회수할 수 있습니다. 가격 숫자 포맷터도 재사용합니다. 앱 전체 CPU·RAM 감소율은 실제 게임 실행 상태에서 아직 측정하지 않았습니다.

시세 서버를 기다리는 동안에도 OCR·사전 확인이 끝나면 아이템 이름·수량을 먼저 표시합니다. 이후 가격과 상세 매물 결과가 도착하면 목록을 갱신합니다. 첫 실행의 사전 다운로드와 고유·젬 공식 거래 검색은 네트워크 상태 및 요청 제한에 따라 시간이 걸립니다. 하단 점은 **회색: 대기 / 초록: 조회 중 / 빨강: 스캔 실패**이며, 서버 연결 상태 자체를 표시하지 않습니다.

[Pretendard](https://github.com/orioncactus/pretendard) 가변 웹폰트를 앱에 포함했습니다. 별도 설치나 실행 중 CDN 접속이 필요하지 않습니다. SIL OFL 라이선스는 `src/fonts/OFL.txt`에 포함합니다.

기본은 실측에서 더 빠르고 가벼웠던 상주 Windows OCR입니다. 오픈소스 RapidOCR도 선택할 수 있습니다 (Python 3.12 권장):

```powershell
py -3.12 -m venv .ocr-venv
./.ocr-venv/Scripts/python.exe -m pip install -r scripts/ocr-requirements.txt
$env:POE_OCR_ENGINE = 'rapidocr'
npm start
```

RapidOCR 모델은 첫 실행에 다운로드되므로 첫 스캔이 느릴 수 있습니다. `POE_OCR_ENGINE=windows`로 다시 Windows OCR을 선택합니다. 모델 추론은 로컬 CPU에서 수행하며 스크린샷을 서버에 업로드하지 않습니다. [OCR 속도·자원 실측](docs/ocr-performance.ko.md)을 참고하세요.

Windows 10/11, Node.js 22 이상, Windows 한국어 OCR 언어 기능이 필요합니다.

```powershell
npm install
npm start
```

1. PoE2를 창/테두리 없는 창 모드로 열고 바닥 라벨을 표시합니다.
2. 기본 리그는 `Forbidden Rites`입니다. 바꾸려면 실행 전 `$env:POE_LEAGUE = '리그 이름'`을 설정하세요.
3. **F6**: 마우스가 있는 모니터 전체를 한 번 캡처하고 한국어 OCR → 사전 일치 → 시세 조회 → 정렬합니다. 게임 모니터에 마우스를 두세요. 오버레이는 Windows 화면 캡처 제외 기능으로 제외하며 스캔할 때 창을 숨기지 않습니다. Windows 10 2004 이상/11을 권장합니다.
4. **F7**: 게임 화면에서 아이템에 마우스를 올려 주변 영역을 캡처합니다. 앱이 게임의 라벨 표시 키를 대신 누르지 않습니다.
5. 판매 전에는 게임에서 아이템을 **Ctrl+C**로 복사한 후 **복사한 아이템 조회**를 누릅니다.

첫 조회는 사전과 여러 가격 분류를 받으므로 시간이 걸립니다. 캡처는 로컬 임시 디렉터리에만 저장하고 스캔이 끝나면 삭제합니다. 게임 메모리 접근이나 주입은 없습니다.

## 구현 범위

- 모니터 전체 OCR 텍스트·좌표. 공식 한국어 사전과 정확히 일치하는 이름만 사용합니다. 게임 외 텍스트도 인식 대상이므로 게임을 전체 화면으로 표시하는 것이 좋습니다.
- 화폐·일부 소모품: 공식 static ID와 poe.ninja ID 연결. `3 x 이름` 또는 `이름 x3` 수량을 곱합니다.
- 엑잘 환산: `core.primary`와 `core.rates` 사용. 리그 기준 화폐가 엑잘인 경우도 처리합니다.
- 고유 이름이 보이면 이름 기준 공식 매물 최대 10개를 조회하고 환산 가능한 매물의 **최저가**로 정렬합니다. 옵션을 확인하지 못한 상태의 참고값이며 전체 시장 최저가를 보장하지 않습니다. 한 스캔당 고유 최대 5종.
- 고유 베이스 이름만 보이면 같은 베이스의 고유 매물을 검색하고 **조회한 매물 중 후보 최저가**를 표시합니다. 후보 이름을 함께 보여 주며 실제 드랍 종류·옵션은 확정하지 않습니다. 최대 10개 중 환산 가능한 매물 기준이므로 전체 시장 최저가를 보장하지 않습니다. 주황색 판별 전에는 일반/마법 장비 베이스도 같은 참고값이 나타날 수 있습니다. 희귀 이름만으로는 가격을 붙이지 않습니다.
- 복사한 한국어 옵션: 공식 사전에서 정확하고 유일하게 대응되는 **단일 수치**를 동일 값의 최솟값·최댓값으로 검색합니다. 대응하지 못한 수치 줄은 결과에 표시합니다.
- `(implicit)` 등 그룹 표기가 있으면 해당 그룹을 사용하며, 표기가 없으면 명시 옵션으로 처리합니다. 그룹이 빠진 복사 텍스트는 검색 조건을 공식 사이트에서 확인해야 합니다.
- 요청 직렬화, 최소 간격, 서버 제한 헤더와 HTTP 429 대기, 15분 가격 캐시, 1분 매물 검색 캐시.
- 상시 위 패널과 공식 검색 결과 링크.
- 매물 비교는 글로벌 `www.pathofexile.com/trade2/search/`에서 엽니다. 한국어 이름·옵션 데이터와 검색 API는 한국어 엔드포인트를 유지합니다.

## 한계와 후속 작업

실제 게임 화면 인식률은 아직 검증하지 않았습니다. 일반 Windows OCR과 2400×1350 이내 캡처이므로 작은 글씨·4K·HDR·라벨 겹침에서 오독할 수 있습니다. 주황색 영역 분리, 한국어 퍼지 매칭, 툴팁 OCR 옵션 파싱, 원래 화면 좌표 복원, 클릭 통과, 게임 포커스에 따른 숨김, 사용자 지정 단축키, 설정 저장, 설치 파일은 후속 작업입니다.

공식 검색은 로그인/서버 정책에 따라 실패할 수 있습니다. 로그인 쿠키 저장이나 인증 우회는 없습니다. 현재 온라인 매물 기준이며 즉시 구매 시장 선택 UI는 후속 작업입니다. 희귀 옵션 검색은 DPS·범위값·타락·품질·소켓을 모두 반영하는 완성된 평가기가 아닙니다.

젬처럼 레벨이 중요한 물품은 전체 이름이 일치하지 않으면 가격화하지 않습니다. 시세가 없을 때 다른 물품 가격으로 대체하지 않습니다. 캐시는 메모리 안에서만 유지됩니다. 매물·집계 시세는 실제 판매가와 다를 수 있습니다.

## 검증

```powershell
npm test
npm run check
node scripts/market-smoke.cjs
node_modules/.bin/electron.cmd . --smoke-test
```

핵심 테스트는 환산, 수량, 위치별 중복, 고유 후보, 옵션 검색, 미확인 장비를 다룹니다. market smoke는 실제 Standard 시세 연결을 검사합니다. UI smoke는 패널/격리된 preload를 확인하고 임시 디렉터리에 PNG를 저장한 뒤 종료합니다.

소스 분석과 설계 판단: [6개 저장소 분석 보고서](docs/repository-analysis.ko.md).

현재 개발 환경에서 GUI 실행은 `UnknownVizError`로 실패해 확인하지 못했습니다. 캡처 영역·가격 처리·UI 갱신·창 상태를 포함한 테스트 28개와 구문 검사는 통과했으며, 실제 게임 화면과 GUI 외형은 후속 검증이 필요합니다.

## 룬 조합 보상 목록

첨부 예시처럼 `3x 상위 제왕의 오브`, `3x 상위 카오스 오브`, `3x 상위 엑잘티드 오브` 등의 보상 목록도 F6으로 읽습니다. 총 가치는 수량 × 개당 집계 시세입니다. `1x`를 `lx` 또는 `1)(`로 읽는 Windows OCR 오독을 수량 접두부에 한정해 보정합니다. 이름과 상위 등급은 공식 사전과 정확히 일치해야 하며, 일반 오브 가격으로 대체하지 않습니다. 같은 보상의 1개/3개 행은 따로 유지합니다. 룬 아이콘 조합 자체를 해석하거나 조합을 추천하는 기능은 포함하지 않습니다.

첨부 이미지 재검증: `node scripts/runeshape-smoke.cjs <이미지.png> [리그]`. 이 스크립트는 예시의 보상 6행에 특화된 검사입니다.

첨부 화면에서 실제 OCR → 공식 한국어 ID → Standard 시세 → 수량 환산을 실행해 6개 보상 행을 모두 가격화했습니다. 총 13개 회귀 테스트도 통과했습니다. 시세는 선택한 리그와 조회 시점에 따라 달라집니다. 게임 전체 모니터를 캡처한 해상도에서도 같은 인식률을 보장하는 결과는 아닙니다.

## 레벨별 젬 보상

`스킬 레벨 20: 베리시움 현신` 같은 행을 공식 젬 사전과 연결하고 거래 검색에 동일 레벨의 최소·최대 조건을 적용합니다. 조회 가능한 매물의 최저가를 표시하며 품질은 미확인 참고값입니다. 고유/젬 검색은 한 스캔에 합계 5종까지만 합니다. `스킬: 이름`, `보조: 이름`처럼 레벨이 없으면 목록에 표시하되 레벨 확인 필요로 남깁니다. `마석학 유동체 (19레벨)`는 별도 공식 static ID로 조회하며 레벨 20 시세로 대체하지 않습니다. `베리시움 더미`는 보상 수량·종류가 불명확하여 확인 필요로 표시합니다.

두 번째 첨부 이미지의 완전하게 보이는 보상 11줄은 Windows OCR로 읽혔습니다. 한국어 공식 items/static 사전에서 젬 7종과 레벨별 마석학 유동체 ID를 확인했습니다. 레벨별 검색 조건을 포함해 테스트 15개가 통과했지만, 젬의 실제 POST 검색/매물 가격과 게임 GUI 동작은 미검증입니다. 현재 인식 엔진은 Windows OCR이며 오픈소스 OCR 교체는 아직 적용하지 않았습니다.

클릭/스캔 때 창을 숨기는 동작을 제거했습니다. 창이 표시되거나 포커스를 받으면 최상위·클릭 가능 상태를 다시 적용하고 최소화 버튼을 비활성화합니다. F8로 명시적으로 숨긴 창은 비동기 조회가 끝나도 다시 나타나지 않습니다. 중복 실행은 기존 창을 열며, 조회 중에는 스캔·옵션 조회·리그 변경을 잠급니다. 조회 시작 시 리그와 클립보드 정보를 고정하고 임시 파일 정리 실패가 다음 조회를 막지 않도록 처리합니다. UI 프로세스 종료 시 최대 두 번 다시 로드합니다. 창 상태 회귀 테스트를 포함해 총 11개 테스트가 통과했습니다. 실제 게임 위 포커스/클릭 검증은 별도로 필요합니다.
